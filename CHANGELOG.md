# Changelog

## [1.0.3] - 2026-10-30

### Added
- **Изолированные инстансы**: каждый профиль имеет свою папку `.minecraft` с модами, сохранениями и настройками.
- Создание инстансов с пользовательским именем (модальное окно с валидацией).
- Удаление инстансов в корзину (`~/.clauncher/trash/`) — как в Prism Launcher. Защита от случайного удаления и от удаления во время игры.
- Поддержка Minecraft **26.x** (year-based версионирование).
- Автоматическая загрузка **Java 25** для версий 26.x.
- **Fabric** теперь работает и на 26.1, 26.2, 26.3 (через API fabricmc.net).

### Changed
- Переход на общий кэш `shared/` (libraries, assets, versions), общий для всех инстансов.
- Динамическое количество потоков G1GC (`ParallelGCThreads = hardware_concurrency() / 2`).
- Разблокировка экспериментальных флагов GC для Java 25+ (`-XX:+UnlockExperimentalVMOptions`).
- Добавлен `-XX:+UseCompactObjectHeaders` для Java 25 (экономия памяти).

### Fixed
- Удалён хардкод-чек `intermediary` в Fabric (ломало запуск 26.x).
- Исправлены пути к `gameDir` при запуске через инстансы.
