# Чек-лист дымового теста CLauncher на Windows

Виртуалка: VirtualBox + образ Windows 10/11 (с включённым 3D-ускорением),
либо любая физическая машина. Тест занимает ~15 минут.

## 0. Подготовка

1. Распаковать `CLauncher-Windows-x64.zip` — внутри папка с `CLauncher-beta.exe`,
   DLL и `cacert.pem`. Все файлы должны лежать вместе.
2. Запустить `CLauncher-beta.exe`.
3. Зафиксировать реакцию SmartScreen (ожидаемо: «Подробнее» → «Выполнить в любом случае»).

Ожидание: открывается окно лаунчера, виден список версий, сверху 1.21.x,
версий 26.x в списке быть не должно.

## 1. Ваниль, офлайн (главный сценарий)

- [ ] Ник латиницей, версия 1.21.x, Vanilla, память 2048 МБ, Play.
- [ ] Прогресс-бар двигается, окно не виснет.
- [ ] JRE скачалась в `%APPDATA%\minecraft-launcher\runtime\java21` без ошибок
      (распаковка должна идти через `tar.exe`, без мигания PowerShell).
- [ ] Клиент, библиотеки и ассеты скачались, игра дошла до главного меню.
- [ ] Создать мир, зайти, выйти из игры.
- [ ] Запустить второй раз — проверка быстро, игра снова стартует; мир на месте.
- [ ] В `%APPDATA%\minecraft-launcher\last_game.pid` записан PID процесса игры.

## 2. Fabric и моды

- [ ] Loader = Fabric, галочка оптимизации включена, Play: Fabric ставится,
      Sodium/Lithium/FerriteCore легли в
      `.minecraft\versions\fabric-loader-...\mods`.
- [ ] Игра стартует через KnotClient, в настройках видео видно Sodium.
- [ ] Кнопка «My Mods» открывает папку модов в проводнике.
- [ ] Кнопка «Resource Packs» открывает `.minecraft\resourcepacks`.

## 3. UI и мелочи

- [ ] Переключение языка EN/RU — русский без «квадратиков»/вопросиков.
- [ ] В поле ника кириллица и спецсимволы не вводятся.
- [ ] Кнопка Discord открывает браузер.
- [ ] Перезапуск лаунчера сохраняет ник, язык и память.
- [ ] Старая версия (например 1.16.5) стартует на Java 8;
      версия 1.18.x — на Java 17 (по логам в консоли).

## 4. Негативные сценарии

- [ ] На время установки выключить интернет и снова включить — после нажатия Play
      загрузка продолжается (упавшие файлы перекачиваются, готовые остаются).
- [ ] Запуск из пути с пробелами (`C:\Test Dir\`) работает.
- [ ] (если возможно) имя пользователя Windows на кириллице — проверить
      скачивание/распаковку Java и запуск.

## Что проверяет код, но без живой Windows не гарантировано

- Транзитивное замыкание DLL и `cacert.pem` собираются в CI по `ldd`;
  на реальной системе нужно подтвердить, что exe стартует и HTTPS работает
  (список версий уже это доказывает — он приходит по HTTPS).
- Путь с кириллицей в имени пользователя — потенциально слабое место:
  вызовы `tar`/установщика Fabric идут через `std::system` (ANSI-кодировка консоли).
