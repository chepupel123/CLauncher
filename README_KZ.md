# CLauncher

Linux және Windows жүйелеріне арналған, C++20 тілінде жазылған, Dear ImGui және OpenGL интерфейсін қолданатын жеңіл Minecraft лаунчері. Ескірген жабдықтарға арнап бір әзірлеуші жасаған: жарнамасыз, телеметриясыз, дүкенсіз, офлайн ойын үшін міндетті аккаунтсыз.

<p align="center">
  <img src="screenshots/interface_ru_vanilla.png" alt="CLauncher интерфейсі (Vanilla)" width="700"/>
</p>

OpenGL 3.0 немесе одан жоғары талап етіледі. Linux (Mint, Ubuntu, Debian) және Windows 10/11 жүйелерінде жұмыс істейді. Бинарлық файлдың өлшемі шамамен үш мегабайт, лаунчер бос тұрғанда шамамен 30–50 МБ жедел жадты (RAM) тұтынады (Minecraft үшін жад интерфейсте бөлек реттеледі). Негізгі әзірлеу және тестілеу компьютері — 2012 жылғы үстел компьютері. Бұл ескірген жабдықтар үшін практикалық бағдар, бірақ кез келген конфигурацияда жұмыс істейді деген кепілдік емес.

## МҮМКІНДІКТЕРІ

* **Vanilla Minecraft орнату.** Клиент, кітапханалар, ассеттер және нативті кітапханалар Mojang-ның ресми серверлерінен автоматты түрде жүктеледі.
* **Fabric қолдауы.** Fabric ресми инсталляторы арқылы орнатылады (лаунчер оның `.jar` файлын өзі іске қосады), жүктеушінің нұсқасы Fabric Meta серверлерінен алынады.
* **Бір батырмамен оңтайландыру модтары.** Sodium, Lithium және FerriteCore. Мод нұсқалары Modrinth API арқылы таңдалған Minecraft нұсқасына сәйкес автоматты түрде таңдалады.

<p align="center">
  <img src="screenshots/interface_ru_fabric.png" alt="CLauncher интерфейсі (Fabric)" width="700"/>
</p>

* **Жеке модтар.** "My Mods" батырмасы нақты Fabric нұсқасының мод қалтасын ашады. Қолмен салынған кез келген `.jar` файлы ойын іске қосылғанда жүктеледі. Әр Minecraft нұсқасының өз мод қалтасы бар, сондықтан әртүрлі нұсқалардың модтары араласпайды (бірақ олар бір-бірімен үйлесімсіз болуы мүмкін, кез келген Fabric сияқты).
* **Ресурс пакеттері.** "Resource Packs" батырмасы жалпы ресурс пакеттер қалтасын ашады. Оған zip мұрағатын салыңыз, содан кейін ойынның ішіндегі ресурс пакеттер мәзірінен қосыңыз.
* **Java-ны автоматты басқару.** Алдымен лаунчер сәйкес келетін жүйелік Java-ны іздейді (`java -version` арқылы). Linux жүйесінде қажет болса, дистрибутивтің пакет менеджерімен (apt, dnf, pacman, zypper немесе apk) қажетті JRE орната алады, ал тіпті қиын жағдайда Adoptium серверлерінен портативті JRE (Minecraft нұсқасына байланысты 8, 17 немесе 21) жүктейді. Windows жүйесінде тек портативті JRE қолданылады.
* **Қатар жүктеу.** Minecraft ассеттері — бұл бірнеше мың ұсақ файл. Лаунчер оларды қосылымдарды қайта пайдалана отырып, он алты ағыннан тұратын пулмен жүктейді, бұл алғашқы орнатуды бір сағаттан бірнеше минутқа қысқартады.
* **Тұтастықты тексеру.** Жүктелетін ойын файлдары (клиент, кітапханалар, нативті кітапханалар және ассеттер), сондай-ақ Modrinth-тан оңтайландыру модтары Mojang немесе Modrinth бақылау сомасын ұсынған жерде SHA1 бойынша тексеріледі. Бүлінген және жүктелмеген файлдар анықталып, келесі іске қосуда автоматты түрде қайта жүктеледі.
* **Жылдам интерфейс.** Барлық орнату фондық ағында жүреді, терезе қатып қалмайды, прогресс нақты уақытта көрінеді.
* **Екі интерфейс тілі.** Ағылшын және орыс тілдері, ауыстырып қосу барысында сақталады.
* **Үш тілдегі құжаттама.** README файлдары ағылшын, орыс және қазақ тілдерінде қолжетімді.
* **Қауіпсіз іске қосу.** Ойын Linux жүйесінде `execv` арқылы, ал Windows жүйесінде `CreateProcessW` арқылы іске қосылады, командалық қабықша тартылмайды. Ұзын classpath argfile арқылы беріледі, сондықтан никтегі ұзындық немесе арнайы таңбалар іске қосуды бұза алмайды.

## ҚОЛДАУ КӨРСЕТІЛЕТІН НҰСҚАЛАР

* **Vanilla және Fabric:** Mojang манифестіндегі 1.x тармағының барлық шығарылымдары, 1.21.x желісіне дейін (Fabric — 1.14.x-тен бастап).
* **26.x желісі** және одан жаңа нұсқалар әдейі қолданылмайды: олар Java 25 және жаңа мод құралдарын талап етеді, лаунчер арналған жабдықтан әлдеқайда жаңа жабдыққа арналған және әзірге тұрақсыз. 26.x үшін ресми лаунчерді пайдаланыңыз. Қолдау желі мен оның мод экожүйесі тұрақтанған кезде пайда болуы мүмкін.

**Жүйелік талаптар:** Linux Mint 21+, Ubuntu 22.04+, Debian 12+, немесе Windows 10 және 11. OpenGL 3.0 және одан жоғары. Дайын AppImage glibc 2.35 немесе одан жаңасын талап етеді. Ескірек жүйелерде бастапқы кодтан құрастыру қажет.

## ЖҮКТЕП АЛУ

Дайын жинақтар [Releases бетінде](https://github.com/chepupel123/CLauncher/releases) орналасқан:

* `CLauncher-Linux.zip` — Linux x86_64. Ішінде — өзін-өзі қамтамасыз ететін `CLauncher-x86_64.AppImage`: қажеттінің бәрі қосылған, қосымша пакеттер қажет емес (glibc 2.35+ қажет; мұрағатты ашыңыз, орындалатын етіп жасаңыз, іске қосыңыз).
* `CLauncher-Windows-x64.zip` — Windows 10/11 x64 (бета, нақты Windows жүйесінде әлі тексерілмеген). Ішінде — қажетті DLL (GLFW/curl) қоса `CLauncher-beta.exe`. Мұрағатты ашып, `.exe` файлын іске қосыңыз.

Егер бастапқы кодтан құрастырғыңыз келсе — нұсқаулық төменде.

## LINUX ЖҮЙЕСІНДЕ ЖЫЛДАМ БАСТАУ

Алдымен тәуелділіктерді орнатыңыз. Терминалда мынаны орындаңыз:

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake git pkg-config unzip \
  libglfw3-dev libgl1-mesa-dev libcurl4-openssl-dev \
  nlohmann-json3-dev libx11-dev libxrandr-dev libxinerama-dev \
  libxcursor-dev fonts-dejavu-core
```

Содан кейін жобаны жүктеңіз: репозиторий бетіндегі "Code" → "Download ZIP" батырмасы (немесе `git clone`) және жоба қалтасына өтіңіз:

```bash
git clone https://github.com/chepupel123/CLauncher.git
cd CLauncher
```

Dear ImGui кітапханасы жобаға қосылған (`extern/imgui` қалтасы), оны қосымша жүктеудің қажеті жоқ.

Құрастырыңыз:

```bash
rm -rf build
mkdir build
cd build
cmake ..
make -j$(nproc)
```

Іске қосыңыз:

```bash
./CLauncher
```

## WINDOWS ЖҮЙЕСІНДЕ ЖЫЛДАМ БАСТАУ

MSYS2 қажет. msys2.org сайтынан орнатушыны жүктеп, `C:\msys64` жеріне орнатыңыз. MSYS2 MINGW64 терминалын ашып, мынаны орындаңыз:

```bash
pacman -Syu
pacman -S --needed mingw-w64-x86_64-gcc mingw-w64-x86_64-cmake \
  mingw-w64-x86_64-ninja mingw-w64-x86_64-curl \
  mingw-w64-x86_64-glfw mingw-w64-x86_64-nlohmann-json make
```

Содан кейін терминалда жоба қалтасына өтіп, құрастырыңыз:

```bash
mkdir build
cd build
cmake .. -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja
```

`CLauncher.exe` файлы пайда болады. Ол MSYS2 жүйесіндегі `glfw3.dll` және `libcurl-4.dll` файлдарымен динамикалық түрде байланысқан: оны MINGW64 қабықшасынан іске қосыңыз немесе осы DLL файлдарын (және олардың тәуелділіктерін) `.exe` жанына қойыңыз — релиздік zip ішінде олар TLS сертификаттарының қоймасы `cacert.pem`-мен бірге жатыр.

Бірінші іске қосу кезінде SmartScreen немесе антивирус ескерту көрсетуі мүмкін, өйткені `.exe` файлына қол қойылмаған: "Подробнее" → "Выполнить в любом случае" түймелерін басыңыз. Java мұрағаттары кірістірілген `tar.exe` арқылы ашылады (Windows 10 1803+), PowerShell тек ескі жүйелердегі қосалқы нұсқа ретінде қолданылады.

## ІШІНДЕ ҚАЛАЙ ЖҰМЫС ІСТЕЙДІ

Play батырмасын басқан кезде лаунчер келесі тізбекті орындайды:

1. `MinecraftInstaller` Mojang манифестімен салыстырып, жетіспейтінді жүктейді: ойын клиенті, кітапханалар, бірнеше мың ассеттер және нативті компоненттер. Қатар жүктеу кезінде әр файл алдымен `.part` уақытша атына жазылады және SHA1 тексеруі сәтті өткеннен кейін ғана қайта аталады; жарияланған бақылау сомасы жоқ файлдар қате болған жағдайда жай ғана қайта сұралады.
2. **Fabric (қосымша).** Егер Fabric таңдалса, Fabric-тің ресми инсталляторы іске қосылады, жүктеуші нұсқасы Fabric Meta-дан алынады, содан кейін Modrinth-тан ойын нұсқаңызға сәйкес келетін Sodium, Lithium және FerriteCore жүктеледі.
3. **JavaManager.** Егер сәйкес Java болмаса, алдымен жүйелікті тексереді, содан кейін Linux жүйесінде қажеттіні дистрибутивтің пакет менеджерімен орнатып көреді, ең соңында Adoptium серверлерінен портативті JRE жүктеп, оны жергілікті қалтаға орналастырады.
4. **JavaLauncher.** Ойын Linux жүйесінде `execv` арқылы немесе Windows жүйесінде `CreateProcessW` арқылы іске қосылады. Лаунчер мен ойын арасында ешқандай командалық қабықша жоқ, ұзын classpath argfile арқылы беріледі. Ойын сәтті іске қосылғаннан кейін лаунчер бір жарым секундтан кейін өзі жабылады, ал ойын процесінің идентификаторы `last_game.pid` файлына сақталады.

**Негізгі архитектуралық шешімдер:**

* Ресми лаунчермен үйлесімді стандартты `.minecraft` қалтасы қолданылады, сондықтан әлемдер, ресурс пакеттер және басқа да ойын деректері ортақ.
* Әр Fabric нұсқасының өз мод қалтасы бар, сондықтан әртүрлі нұсқалардың модтары араласпайды.
* Әр іске қосу кезінде орнатылғанның тұтастығы тексеріледі және тек жетіспейтін немесе бүлінген нәрселер ғана жүктеледі.
* Fabric профильдері үшін ассеттер индексі мұрагерлік (`inheritsFrom`) арқылы негізгі ванильді нұсқадан алынады.

## ПАЙДАЛАНУ

1. Никті енгізіңіз. Тек латын әріптері, сандар және астыңғы сызықша, басқа таңбалар автоматты түрде сүзіледі.
2. Тізімнен нұсқаны таңдаңыз. Тізім Mojang-ның ресми манифестінен алынады және кэштеледі, сондықтан интернетсіз де жұмыс істейді.
3. Жүктеушіні таңдаңыз: Vanilla немесе Fabric. Fabric үшін оңтайландыру модтарының құсбелгісі қолжетімді.
4. Жад көлемін таңдаңыз. 2048 мегабайт ұсынылады.
5. Play батырмасын басыңыз. Алғашқы орнату жылдам емес; келесі іске қосуларда орнатылған нәрсе тек тексеріліп, жетіспейтіні жүктеледі, сондықтан олар әлдеқайда жылдам.

"My Mods" батырмасы ағымдағы Fabric нұсқасының мод қалтасын ашады. "Resource Packs" батырмасы ресурс пакеттер қалтасын ашады. Жоғарғы оң жақ бұрышта — тіл ауыстырғышы.

## НЕ ҚАЙДА ЖАТЫР

**Linux жүйесінде:**

* Ойын: үй каталогындағы `.minecraft` қалтасында
* Әлемдер: `.minecraft/saves`
* Модтар: `.minecraft/versions/нұсқа-аты/mods`
* Ресурс пакеттер: `.minecraft/resourcepacks`
* Жүктелген Java: `.minecraft-launcher/runtime`
* Лаунчер параметрлері: `.minecraft-launcher/launcher_settings.json`

**Windows жүйесінде:**

* Ойын: пайдаланушы каталогыңыздағы `.minecraft` қалтасында
* Модтар мен әлемдер: Linux жүйесіндегідей
* Жүктелген Java және лаунчер параметрлері: AppData Roaming ішіндегі `minecraft-launcher` қалтасында

## АККАУНТСЫЗ ОЙЫНШЫ ИДЕНТИФИКАТОРЫ

Лаунчер никтен стандартты Minecraft `OfflinePlayer:` схемасы бойынша детерминді офлайн-UUID жасайды (3-нұсқадағы аталған MD5-UUID) — бұл офлайн режиміндегі сервердің никтен есептейтін идентификаторымен бірдей. Ол іске қосулар арасында тұрақты, сондықтан әлемдердегі прогресс дұрыс сақталады.

## БЕЛГІЛІ ШЕКТЕУЛЕР

* 26.x желісі толығымен қолданылмайды (ванильді қоса): ол Java 25 талап етеді, лаунчерге арналғаннан жаңарақ жабдыққа арналған және әзірге тұрақсыз. 1.21.x немесе одан ескісін таңдаңыз.
* Windows орындалатын файлына қол қойылмаған, сондықтан SmartScreen немесе антивирус бірінші іске қосу кезінде ескерту көрсетуі мүмкін ("Подробнее" → "Выполнить в любом случае"). Java кірістірілген `tar.exe` арқылы ашылады (PowerShell — тек ескі жүйелердегі қосалқы нұсқа).
* Алғашқы орнату жылдам емес: бірнеше мың ассет файлдары. Келесі іске қосулар әлдеқайда жылдам: бәрі кэштеледі және SHA1 бойынша тексеріледі, тек жетіспейтіні ғана қайта жүктеледі.
* Никтегі кириллица әдейі қабылданбайды: ник серверлерде және әлем файлдарында қолданылады, онда таңбалардың шектеулі жиынтығы ғана қауіпсіз.

## ЕГЕР БІРДЕҢЕ ІСТЕМЕСЕ

* **`GLFW init failed` қатесі.** GLFW орнатылмаған немесе іске қосу графикалық сессияда емес. `libglfw3-dev` орнатыңыз.
* **Мәтіннің орнына сұрақ белгілері.** Кириллицаны қолдайтын қаріп табылмады. `fonts-dejavu-core` орнатыңыз.
* **Java жүктеу сәтсіз аяқталды.** Интернетті тексеріңіз немесе Java-ны қолмен орнатыңыз: егер мажорлық нұсқа сәйкес келсе, лаунчер жүйелікті пайдаланады.
* **Дыбыстар жоғалды немесе тілдер тізімі бос.** Осы нұсқада Play батырмасын тағы басыңыз: лаунчер ассеттерді тексеріп, жетіспейтінін жүктейді.
* **Ойын іске қосылғаннан кейін бірден шығып кетеді.** Көбінесе мод сіздің Minecraft нұсқаңызға сай емес. Оны мод қалтасынан жойыңыз.
