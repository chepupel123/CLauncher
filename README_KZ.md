# CLauncher

Linux және Windows жүйелеріне арналған, C++20 тілінде жазылған, Dear ImGui және OpenGL интерфейсін қолданатын жеңіл Minecraft лаунчері. Ескірген жабдықтарға арнап бір әзірлеуші жасаған: жарнамасыз, телеметриясыз, дүкенсіз, офлайн ойын үшін міндетті аккаунтсыз.

OpenGL 3.0 немесе одан жоғары талап етіледі. Linux (Mint, Ubuntu, Debian) және Windows 10/11 жүйелерінде жұмыс істейді. Бинарлық файлдың өлшемі шамамен үш мегабайт, лаунчер бос тұрғанда шамамен 30–50 МБ жедел жадты (RAM) тұтынады (Minecraft үшін жад интерфейсте бөлек реттеледі). Негізгі әзірлеу және тестілеу компьютері — 2012 жылғы үстел компьютері. Бұл ескірген жабдықтар үшін практикалық бағдар, бірақ кез келген конфигурацияда жұмыс істейді деген кепілдік емес.

## МҮМКІНДІКТЕРІ

* **Vanilla Minecraft орнату.** Клиент, кітапханалар, ассеттер және нативті кітапханалар Mojang-ның ресми серверлерінен автоматты түрде жүктеледі.
* **Fabric қолдауы.** Fabric ресми инсталляторы арқылы орнатылады (лаунчер оның `.jar` файлын өзі іске қосады), жүктеушінің нұсқасы Fabric Meta серверлерінен алынады.
* **Бір батырмамен оңтайландыру модтары.** Sodium, Lithium және FerriteCore. Мод нұсқалары Modrinth API арқылы таңдалған Minecraft нұсқасына сәйкес автоматты түрде таңдалады.
* **Жеке модтар.** "My Mods" батырмасы нақты Fabric нұсқасының мод қалтасын ашады. Қолмен салынған кез келген `.jar` файлы ойын іске қосылғанда жүктеледі. Әр Minecraft нұсқасының өз мод қалтасы бар, сондықтан әртүрлі нұсқалардың модтары араласпайды (бірақ олар бір-бірімен үйлесімсіз болуы мүмкін, кез келген Fabric сияқты).
* **Ресурс пакеттері.** "Resource Packs" батырмасы жалпы ресурс пакеттер қалтасын ашады. Оған zip мұрағатын салыңыз, содан кейін ойынның ішіндегі ресурс пакеттер мәзірінен қосыңыз.
* **Java-ны автоматты басқару.** Алдымен лаунчер сәйкес келетін жүйелік Java-ны іздейді (`java -version` арқылы). Linux жүйесінде қажет болса, дистрибутивтің пакет менеджерімен (apt, dnf, pacman, zypper немесе apk) қажетті JRE орната алады, ал тіпті қиын жағдайда Adoptium серверлерінен портативті JRE (Minecraft нұсқасына байланысты 8, 17 немесе 21) жүктейді. Windows жүйесінде тек портативті JRE қолданылады.
* **Қатар жүктеу.** Minecraft ассеттері — бұл бірнеше мың ұсақ файл. Лаунчер оларды қосылымдарды қайта пайдалана отырып, он алты ағыннан тұратын пулмен жүктейді, бұл алғашқы орнатуды бір сағаттан бірнеше минутқа қысқартады.
* **Тұтастықты тексеру.** Жүктелетін ойын файлдары (клиент, кітапханалар, нативті кітапханалар және ассеттер), сондай-ақ Modrinth-тан оңтайландыру модтары Mojang немесе Modrinth бақылау сомасын ұсынған жерде SHA1 бойынша тексеріледі. Бүлінген және жүктелмеген файлдар анықталып, келесі іске қосуда автоматты түрде қайта жүктеледі.
* **Жылдам интерфейс.** Барлық орнату фондық ағында жүреді, терезе қатып қалмайды, прогресс нақты уақытта көрінеді.
* **Екі интерфейс тілі.** Ағылшын және орыс тілдері, ауыстырып қосу барысында сақталады.
* **Қауіпсіз іске қосу.** Ойын Linux жүйесінде `execv` арқылы, ал Windows жүйесінде `CreateProcessW` арқылы іске қосылады, командалық қабықша тартылмайды. Ұзын classpath argfile арқылы беріледі, сондықтан никтегі ұзындық немесе арнайы таңбалар іске қосуды бұза алмайды.

## ҚОЛДАУ КӨРСЕТІЛЕТІН НҰСҚАЛАР

Vanilla және Fabric: Mojang манифестіндегі 1.x тармағының барлық шығарылымдары, 1.21.x желісіне дейін (Fabric — 1.14.x-тен бастап).

26.x желісі және одан жаңа нұсқалар әдейі қолданылмайды: олар Java 25 және жаңа мод құралдарын талап етеді, лаунчер арналған жабдықтан әлдеқайда жаңа жабдыққа арналған және әзірге тұрақсыз. 26.x үшін ресми лаунчерді пайдаланыңыз. Қолдау желі мен оның мод экожүйесі тұрақтанған кезде пайда болуы мүмкін.

**Жүйелік талаптар:** Linux Mint 21+, Ubuntu 22.04+, Debian 12+, немесе Windows 10 және 11. OpenGL 3.0 және одан жоғары. Дайын AppImage glibc 2.35 немесе одан жаңасын талап етеді. Ескірек жүйелерде бастапқы кодтан құрастыру қажет.

## ЖҮКТЕП АЛУ

Дайын жинақтар Releases бетінде орналасқан:

* **CLauncher-Linux.zip** — Linux x86_64. Ішінде — өзін-өзі қамтамасыз ететін `CLauncher-x86_64.AppImage`: қажеттінің бәрі қосылған, қосымша пакеттер қажет емес (glibc 2.35+ қажет; мұрағатты ашыңыз, орындалатын етіп жасаңыз, іске қосыңыз).
* **CLauncher-Windows-x64.zip** — Windows 10/11 x64 (бета, нақты Windows жүйесінде әлі тексерілмеген). Ішінде — қажетті DLL (GLFW/curl) қоса `CLauncher-beta.exe`. Мұрағатты ашып, `.exe` файлын іске қосыңыз.

Егер бастапқы кодтан құрастырғыңыз келсе — нұсқаулық төменде.
