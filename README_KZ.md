# CLauncher

Linux және Windows жүйелеріне арналған, C++20 тілінде жазылған, Dear ImGui және OpenGL интерфейсін қолданатын жеңіл Minecraft лаунчері. Ескірген жабдықтарға арнап бір әзірлеуші жасаған: жарнамасыз, телеметриясыз, дүкенсіз, офлайн ойын үшін міндетті аккаунтсыз.

<p align="center">
  <img src="screenshots/interface_ru_vanilla.png" alt="CLauncher интерфейсі (Vanilla)" width="700"/>
</p>

**OpenGL 3.3 Core** немесе одан жоғары талап етіледі. Linux (Debian, Ubuntu, Mint, Kali, Fedora, Arch, openSUSE, Alpine және басқа дистрибутивтер) және Windows 10/11 жүйелерінде жұмыс істейді. Бинарлық файлдың өлшемі шамамен үш мегабайт, лаунчер бос тұрғанда шамамен 30–50 МБ жедел жадты (RAM) тұтынады (Minecraft үшін жад интерфейсте бөлек реттеледі). Негізгі әзірлеу және тестілеу компьютері — 2012 жылғы үстел компьютері. Бұл ескірген жабдықтар үшін практикалық бағдар, бірақ кез келген конфигурацияда жұмыс істейді деген кепілдік емес.

## МҮМКІНДІКТЕРІ

* **Vanilla Minecraft-ты тікелей лаунчерден орнату.** Клиент, кітапханалар, ассеттер және нативті кітапханалар Mojang-ның ресми серверлерінен автоматты түрде жүктеледі.
* **Fabric қолдауы (Minecraft 1.14+).** Fabric ресми инсталляторы арқылы орнатылады (лаунчер оның `.jar` файлын өзі іске қосады), жүктеушінің нұсқасы Fabric Meta серверлерінен алынады. Ескі нұсқалар үшін Fabric опциясы жасырылады.
* **Бір құсбелгімен оңтайландыру модтары.** Fabric API, Sodium, Lithium және FerriteCore. Мод нұсқалары Modrinth API арқылы таңдалған Minecraft нұсқасына автоматты түрде сәйкестендіріледі.
* **Log4Shell-тен қорғаныс.** Лаунчер 1.18.1-ден төмен барлық Minecraft нұсқалары үшін `-Dlog4j2.formatMsgNoLookups=true` аргументін автоматты түрде қосады, осылайша сізді маңызды қауіпсіздік осалдығынан (CVE-2021-44228) қорғайды.
* **Ақылды қатар жүктеу.** Бейімделгіш ағындар пулы файлдар саны мен процессор ядроларын талдайды, осылайша ассеттерді 3–4 есе жылдам жүктейді. Жылдамдық пен ETA (қалған уақыт) есептеуі дәл және жедел.
* **Орнатуды болдырмау.** Жүктеу кезінде лаунчер терезесін қауіпсіз жабуға болады, ал фондық орнату процесі ойынды іске қоспай дұрыс тоқтайды.

  <img src="screenshots/interface_ru_fabric.png" alt="CLauncher интерфейсі (Fabric)" width="700"/>
</p>

* **Жеке модтар.** «Менің модтарым» батырмасы нақты Fabric нұсқасының мод қалтасын ашады. Қолмен салынған кез келген `.jar` файлы ойын іске қосылғанда жүктеледі. Әр Minecraft нұсқасының өз мод қалтасы бар, сондықтан әртүрлі нұсқалардың модтары араласпайды.
* **Ресурс пакеттері.** «Ресурс пакеттері» батырмасы жалпы ресурс пакеттер қалтасын ашады. Оған zip мұрағатын салыңыз, содан кейін ойынның ішіндегі ресурс пакеттер мәзірінен қосыңыз.
* **Java-ны автоматты басқару.** Лаунчер енді жүйелік пакет менеджерлеріне (apt, dnf, pacman) тәуелді емес және `sudo` қажет етпейді. Ол әрқашан таңдалған Minecraft нұсқасына сәйкес портативті JRE-ны (8, 17, 21) Adoptium серверлерінен өз қалтасына жүктейді. Кез келген дистрибутивте қораптан шыққан бойы жұмыс істейді.
* **Тұтастықты тексеру.** Жүктелетін ойын файлдары, сондай-ақ Modrinth модтары Mojang немесе Modrinth бақылау сомасын ұсынған жерде SHA1 бойынша (OpenSSL арқылы) тексеріледі. Бүлінген және жүктелмеген файлдар анықталып, автоматты түрде қайта жүктеледі.
* **Қосарлы іске қосудан қорғаныс.** CLauncher кездейсоқ екі рет іске қосылса, екінші терезе бірден жабылады — екі процесс бір уақытта бір қалтаға ассеттерді жүктемейді.
* **Сессияны сақтау.** Лақап аты, таңдалған Minecraft нұсқасы, мод жүктеушісі, жад және тіл іске қосулар арасында сақталады.
* **Тереземен дұрыс жұмыс.** Play басылғанда лаунчер терезесі ойын жүріп жатқанда жасырылады және Minecraft-тан шыққаннан кейін автоматты түрде қайта оралады.
* **Жылдам интерфейс.** Барлық орнату фондық ағында жүреді, терезе қатып қалмайды, прогресс нақты уақытта көрінеді. Тілді тіпті жүктеу барысында да ауыстыра аласыз.
* **Екі интерфейс тілі.** Ағылшын және орыс тілдері, ауыстырып қосу барысында сақталады.
* **Файлға логтау.** Лаунчер шығаратынның бәрі `~/.clauncher/logs/` қалтасындағы `clauncher.log` файлына (немесе Windows жүйесінде `%APPDATA%\CLauncher\logs\`) жазылады.
* **Қауіпсіз іске қосу.** Ойын Linux жүйесінде `execv` арқылы, ал Windows жүйесінде `CreateProcessW` арқылы іске қосылады, командалық қабықша тартылмайды. Ұзын classpath argfile арқылы беріледі, сондықтан никтегі ұзындық немесе арнайы таңбалар іске қосуды бұза алмайды.

## ҚОЛДАУ КӨРСЕТІЛЕТІН НҰСҚАЛАР

* **Vanilla және Fabric:** Mojang манифестіндегі 1.x тармағының барлық шығарылымдары, 1.21.x желісіне дейін (Fabric — 1.14.x-тен бастап).
* **26.x желісі** 1.0.2-де уақытша қолданылмайды. Ол Java 25 және жаңа мод құралдарын талап етеді, олар әлі тұрақтандырылуда. **26.x қолдауы 1.0.4 нұсқасында жоспарланған ([Жоспарлар](#жоспарлар) қараңыз).**

**Жүйелік талаптар:** glibc 2.35+ және **OpenGL 3.3 Core** бар кез келген заманауи Linux дистрибутиві, немесе Windows 10 және 11. Дайын AppImage glibc 2.35 немесе одан жаңасын талап етеді; ескірек жүйелерде бастапқы кодтан құрастырыңыз.

## ЖҮКТЕП АЛУ

Дайын жинақтар [Releases бетінде](https://github.com/chepupel123/CLauncher/releases) орналасқан:

* `CLauncher-Linux.zip` — Linux x86_64. Ішінде — өзін-өзі қамтамасыз ететін `CLauncher-x86_64.AppImage`: қажеттінің бәрі қосылған, қосымша пакеттер қажет емес (glibc 2.35+ қажет; мұрағатты ашыңыз, орындалатын етіп жасаңыз, іске қосыңыз).
* `CLauncher-Windows-x64.zip` — Windows 10/11 x64 (бета, нақты Windows жүйесінде әлі толық тексерілмеген). Ішінде — `CLauncher.exe` қажетті DLL (GLFW/curl/OpenSSL) және `cacert.pem` қоса; мұрағатты ашып, `.exe` файлын іске қосыңыз.

Егер бастапқы кодтан құрастырғыңыз келсе — нұсқаулық төменде.

## LINUX ЖҮЙЕСІНДЕ ЖЫЛДАМ БАСТАУ

Алдымен тәуелділіктерді орнатыңыз. Терминалда мынаны орындаңыз:

**Debian / Ubuntu / Mint / Kali / Pop!_OS:**
```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake git pkg-config unzip \
  libglfw3-dev libgl1-mesa-dev libcurl4-openssl-dev libssl-dev \
  nlohmann-json3-dev libx11-dev libxrandr-dev libxinerama-dev \
  libxcursor-dev fonts-dejavu-core
```

**Fedora / RHEL / CentOS Stream:**
```bash
sudo dnf install -y gcc-c++ cmake git pkg-config unzip \
  glfw-devel mesa-libGL-devel libcurl-devel openssl-devel \
  nlohmann-json-devel libX11-devel libXrandr-devel \
  libXinerama-devel libXcursor-devel dejavu-sans-fonts
```

**Arch / Manjaro / EndeavourOS:**
```bash
sudo pacman -S --needed base-devel cmake git pkg-config unzip \
  glfw mesa curl openssl nlohmann-json libx11 libxrandr \
  libxinerama libxcursor ttf-dejavu
```

Содан кейін жобаны жүктеп, құрастырыңыз:

```bash
git clone https://github.com/chepupel123/CLauncher.git
cd CLauncher
rm -rf build
mkdir build
cd build
cmake ..
make -j$(nproc)
```

Іске қосыңыз:

```bash
./CLauncher
```

## WINDOWS ЖҮЙЕСІНДЕ ЖЫЛДАМ БАСТАУ

**MSYS2** қажет. Орнатушыны msys2.org сайтынан жүктеп, `C:\msys64` жеріне орнатыңыз. **MSYS2 UCRT64** терминалын ашып (MINGW64 емес!), мынаны орындаңыз:

```bash
pacman -Syu
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake \
  mingw-w64-ucrt-x86_64-ninja mingw-w64-ucrt-x86_64-curl \
  mingw-w64-ucrt-x86_64-openssl mingw-w64-ucrt-x86_64-glfw \
  mingw-w64-ucrt-x86_64-nlohmann-json make
```

Содан кейін жоба қалтасына өтіп, құрастырыңыз:

```bash
mkdir build
cd build
cmake .. -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja
```

`CLauncher.exe` файлы пайда болады. Релиздік zip ішінде барлық қажетті DLL және `cacert.pem` (TLS сертификаттарының қоймасы) жатыр.

## ІШІНДЕ ҚАЛАЙ ЖҰМЫС ІСТЕЙДІ

Play батырмасын басқан кезде лаунчер келесі тізбекті орындайды:

1. **MinecraftInstaller** Mojang манифестімен синхрондалып, жетіспейтінді жүктейді: ойын клиенті, кітапханалар, бірнеше мың ассет файлдары және нативті компоненттер. Бейімделгіш жүктеу пулы жылдамдықты сіздің жабдығыңызға қарай оңтайландырады.
2. **Fabric (қосымша).** Егер таңдалса, Fabric-тің ресми инсталляторы қауіпсіз staging қалтасында іске қосылады, содан кейін Modrinth-тан ойын нұсқаңызға сәйкес Fabric API, Sodium, Lithium және FerriteCore жүктеледі.
3. **JavaManager** қажетті портативті JRE-ны (ойын нұсқасына байланысты Java 8, 17 немесе 21) Adoptium серверлерінен жүктеп, лаунчер қалтасында кэштеліп қоймаған жағдайда оны распаковкалайды.
4. **JavaLauncher** ойынды `execv` (Linux) немесе `CreateProcessW` (Windows) арқылы іске қосады. Лаунчер мен ойын арасында қабықша жоқ, ұзын classpath argfile арқылы беріледі.
5. Ойын жүріп жатқанда лаунчер терезесі жасырылады. Minecraft-тан шыққан кезде терезе автоматты түрде қайта оралады және келесі іске қосуға дайын.

## НЕ ҚАЙДА ЖАТЫР

**Linux жүйесінде:**
* Ойын (әлемдер, модтар, конфигтер): `~/.minecraft/`
* Лаунчер параметрлері, кэш, JRE: `~/.clauncher/` (атап айтқанда `~/.clauncher/runtime/` және `~/.clauncher/launcher_settings.json`)
* Лаунчер логы: `~/.clauncher/logs/clauncher.log`

**Windows жүйесінде:**
* Ойын: `%USERPROFILE%\.minecraft\`
* Лаунчер параметрлері, кэш, JRE: `%APPDATA%\CLauncher\`
* Лаунчер логы: `%APPDATA%\CLauncher\logs\clauncher.log`

## ОФЛАЙН ОЙЫНШЫ ИДЕНТИФИКАТОРЫ

Лаунчер никтен стандартты Minecraft OfflinePlayer схемасы бойынша детерминді офлайн-UUID жасайды (атауға негізделген MD5-UUID, 3-нұсқа). Ол іске қосулар арасында тұрақты, сондықтан әлемдердегі прогресс дұрыс сақталады.

## БЕЛГІЛІ ШЕКТЕУЛЕР

* Windows орындалатын файлына қол қойылмаған, сондықтан SmartScreen немесе антивирус бірінші іске қосу кезінде ескерту көрсетуі мүмкін («Подробнее» → «Выполнить в любом случае»).
* Алғашқы орнату жылдам емес: бірнеше мың ассет файлдары. Келесі іске қосулар әлдеқайда жылдам, өйткені бәрі кэштеледі және SHA1 бойынша тексеріледі.
* Никтегі кириллица әдейі қабылданбайды: ник серверлерге және әлем файлдарына барады, онда таңбалардың шектеулі жиынтығы ғана қауіпсіз.

## ЕГЕР БІРДЕҢЕ ІСТЕМЕСЕ

* **GLFW init failed қатесі:** GLFW орнатылмаған немесе лаунчерді графикалық сессиядан тыс іске қосып жатырсыз.
* **Мәтіннің орнына сұрақ белгілері:** кириллицаны қолдайтын қаріп табылмады. `fonts-dejavu-core` (Debian/Ubuntu), `dejavu-sans-fonts` (Fedora), `ttf-dejavu` (Arch) орнатыңыз.
* **Ойын іске қосылғаннан кейін бірден шығып кетеді:** көбінесе қалтада басқа Minecraft нұсқасына арналған мод бар. Оны `mods` ішінен жойыңыз.
* **Жүктеу ортасында тоқтады:** Play батырмасын қайта басыңыз — жүктелген файлдар сақталады және SHA1 бойынша тексеріледі, тек жетіспейтіндері ғана қайта жүктеледі.
